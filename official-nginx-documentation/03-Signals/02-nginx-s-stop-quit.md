# quit stop signal
---

**سیگنال‌های `quit` و `stop` هر دو برای متوقف‌کردن Nginx استفاده می‌شن؛ تفاوتشون در نحوهٔ برخورد با درخواست‌های در حال پردازشه.**

**۱. سیگنال `quit`: توقف آرام (Graceful shutdown)**

```
nginx -s quit
```

با این دستور، Nginx پذیرش اتصال‌های جدید رو متوقف می‌کنه، اما به Workerها اجازه می‌ده درخواست‌های جاری رو تمام کنن و بعد خارج بشن.

**چه زمانی استفاده می‌شه؟** وقتی می‌خوای Nginx رو برای کارهایی مثل نگهداری سرور متوقف کنی و فرصت داری صبر کنی تا پردازش درخواست‌های کاربران تمام بشه.

**۲. سیگنال `stop`: توقف سریع (Fast shutdown)**

```
nginx -s stop
```

با این دستور، Nginx سریع متوقف می‌شه و منتظر پایان درخواست‌های جاری نمی‌مونه؛ بنابراین ممکنه بعضی درخواست‌ها نیمه‌کاره بمونن.

**چه زمانی استفاده می‌شه؟** وقتی لازم داری سرویس سریع متوقف بشه و منتظر تمام‌شدن درخواست‌ها نمی‌مونی. این دو نوع توقف در مستندات رسمی مشخص شده‌اند. 

|ویژگی|`quit`|`stop`|
|---|---|---|
|نوع توقف|آرام و با فرصت اتمام کار|سریع|
|درخواست‌های جاری|فرصت تمام‌شدن دارن|ممکنه قطع بشن|
|زمان خروج|به اتمام درخواست‌ها بستگی داره|منتظر اتمام درخواست‌ها نمی‌مونه|

مثلاً اگر کاربری در حال دانلود فایل باشه، **`quit` فرصت می‌ده دانلود تمام بشه**؛ اما **`stop` ممکنه دانلود رو وسط کار قطع کنه**.
