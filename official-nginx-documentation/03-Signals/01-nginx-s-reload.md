# reload signal
---
**سیگنال `reload` برای خواندن دوباره و اعمال تنظیمات Nginx استفاده می‌شه.** وقتی فایل تنظیمات رو تغییر می‌دی، صرفاً ذخیره‌کردن فایل باعث اعمال تغییرات نمی‌شه؛ باید به Nginx بگی تنظیمات جدید رو بخونه.

```
nginx -s reload
```

با دریافت این سیگنال، **Master Process** تنظیمات جدید رو بررسی می‌کنه. اگر قابل اعمال باشن، Workerهای جدید رو با این تنظیمات اجرا می‌کنه؛ Workerهای قبلی هم درخواست‌های جاری رو تمام می‌کنن و خارج می‌شن. اگر اعمال تنظیمات جدید شکست بخوره، Nginx با تنظیمات قبلی به کارش ادامه می‌ده. 

**کجا استفاده می‌شه؟** مثلاً وقتی:

- دامنه یا سایت جدیدی به تنظیمات اضافه می‌کنی.
- پورت یا مسیر فایل‌های سایت رو تغییر می‌دی.
- تنظیمات Reverse Proxy رو عوض می‌کنی.
- تنظیمات یا فایل گواهی SSL رو به‌روزرسانی می‌کنی.

روش معمول اینه که اول تنظیمات رو بررسی کنی:

```
nginx -t
```

و اگر بررسی موفق بود، اون‌ها رو اعمال کنی:

```
nginx -s reload
```

فلگ `-t` ساختار تنظیمات و امکان بازکردن فایل‌های اشاره‌شده در اون‌ها رو بررسی می‌کنه.
