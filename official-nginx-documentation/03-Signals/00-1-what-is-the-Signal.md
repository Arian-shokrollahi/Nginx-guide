# ۱- سیگنال در Nginx به چه معناست؟

**سیگنال (Signal)** در Nginx یعنی پیامی که به فرایند اصلی برنامه، یعنی **Master Process**، می‌فرستی تا کاری انجام بده؛ مثلاً تنظیمات جدید رو بخونه یا برنامه رو متوقف کنه.
-  و شما به کمک فلگ s- به nginx میگید که چه پیغامی رو به پردازه اصلی (Master process) ارسال کنه

### ۲- نکات پایانی درمورد سیگنال ها:

- **سیگنال‌ها برای کنترل Nginx در حال اجرا استفاده می‌شن** و با فلگ `-s` به پردازهٔ اصلی (**Master Process**) ارسال می‌شن.

- پردازهٔ اصلی با دریافت سیگنال، اقدام لازم رو انجام می‌ده و پردازه‌های **Worker** رو مدیریت می‌کنه.

- چهار فرمان قابل استفاده با `-s` عبارت‌اند از: **`stop`، `quit`، `reload` و `reopen`**.
- ا-**`stop` توقف سریع** انجام می‌ده، اما **`quit` اجازه می‌ده درخواست‌های جاری تمام بشن** و سپس برنامه متوقف بشه.

- ا-**`reload` برای اعمال تغییرات تنظیمات** و **`reopen` برای بازکردن دوباره فایل‌های لاگ** استفاده می‌شه.
