#  کامنت چیست # و ما چرا از کامنت استفاده میکنیم
---
ا-**Comment (کامنت)** یعنی بخشی از متن داخل فایل تنظیمات که توسط برنامه **خوانده و اجرا نمی‌شود**؛ یعنی Nginx آن قسمت را نادیده می‌گیرد.

در Nginx برای نوشتن کامنت از علامت **`#`** استفاده می‌کنیم:

```
# This is a comment
worker_processes auto;
```

در این مثال:

- خط اول فقط توضیح است و Nginx آن را اجرا نمی‌کند.
- خط دوم یک دستور واقعی است و Nginx آن را اجرا می‌کند.

### چرا کامنت می‌گذاریم؟

**۱. توضیح دادن تنظیمات**

برای اینکه بعداً خودمان یا افراد دیگر بفهمند هر بخش چه کاری انجام می‌دهد.

مثال:

```
# Number of worker processes
worker_processes auto;
```

---

**۲. غیرفعال کردن موقت یک تنظیم**

به جای حذف کردن یک خط، می‌توانیم آن را کامنت کنیم:

```
# listen 80;
```

در این حالت Nginx دیگر این دستور را اجرا نمی‌کند.

---

**۳. مرتب و قابل فهم کردن فایل تنظیمات**

فایل‌های Nginx ممکن است بزرگ شوند؛ کامنت‌ها مثل یادداشت کنار کد عمل می‌کنند.

مثال:

```
http {

    # Website configuration
    server {
        listen 80;
    }

}
```

---

**نکته مهم:**

در Nginx هر چیزی بعد از علامت `#` در همان خط، کامنت محسوب می‌شود:

```
worker_connections 1024; # Maximum number of connections
```

اینجا:

- `worker_connections 1024;` → دستور واقعی
- `# Maximum number of connections` → فقط توضیح

پس خلاصه:

ا-**Comment = توضیح یا یادداشت برای انسان‌ها که Nginx آن را اجرا نمی‌کند.**
