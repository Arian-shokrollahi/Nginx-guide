# مسیر لاگ nginx کجاست
---
### 1-مسیر رایجه فایل هایه لاگ درون nginx

مسیر رایج فایل‌های لاگ Nginx در نصب‌های لینوکسی اینه:

```
/var/log/nginx/access.log
/var/log/nginx/error.log
```

|فایل|محتوا|
|---|---|
|`access.log`|اطلاعات درخواست‌های کاربران، مثل مسیر درخواست و کد پاسخ|
|`error.log`|خطاها و مشکلات Nginx|

**مسیر دقیق به تنظیمات نصب تو بستگی داره.** در فایل‌های تنظیمات با این دستورها مشخص می‌شه:

```
access_log /var/log/nginx/access.log;
error_log /var/log/nginx/error.log;
```

---

## 2- اگر مسیر بالا نبود این رو بزنید
برای پیدا‌کردن مسیرهای تنظیم‌شده در سیستم خودت:

```
sudo nginx -T 2>&1 | grep -E 'access_log|error_log'
```

فلگ **`-T`** تنظیمات Nginx رو نمایش می‌ده و این دستور خط‌های مربوط به لاگ رو جدا می‌کنه.

---
##  3- یه نکته مهم درمورد داکر 

اگر از **ایمیج رسمی Nginx در Docker** استفاده می‌کنی، لاگ‌ها معمولاً به خروجی کانتینر هدایت می‌شن و با این دستور می‌بینیشون:

```
docker logs container_name
```

به‌جای `container_name` اسم کانتینرت رو بنویس.
