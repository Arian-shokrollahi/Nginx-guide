### What is nginx
### بعد هم لازم میدونم اول بهتون توضیح بدم که nginx چیه خیلی کوتاه و فنی که بعدش بریم سراغه توضیحه  قسمت به قسمت مستندات nginx تا بفهمیم واقعا nginx  یعنی چی ؟
- توضیح فنیش

> انجین‌ایکس (Nginx) یک وب‌سرور است که می‌تواند به‌عنوان پراکسی معکوس و توزیع‌کنندهٔ بار نیز عمل کند. معماری آن مبتنی بر رویداد (event-based) است و برای مدیریت ارتباطات شبکه از ورودی‌وخروجی غیرمسدودکننده (non-blocking I/O) استفاده می‌کند. این طراحی به هر پردازش کاری (worker process) اجازه می‌دهد تعداد زیادی اتصال را هم‌زمان مدیریت کند، بدون اینکه برای هر اتصال یک پردازش جدا ایجاد شود. انجین‌ایکس برای تشخیص آماده بودن اتصال‌ها جهت خواندن یا نوشتن، از سازوکارهای متناسب با سیستم‌عامل، مانند اپول (epoll) در لینوکس و کیوکیو (kqueue) در فری‌بی‌اس‌دی، استفاده می‌کند.

**معنی غیرمسدودکننده:** وقتی یک اتصال منتظر رسیدن داده است، پردازش کاری می‌تواند به اتصال‌های دیگر رسیدگی کند.

- توضیح سادش
- ا-**NGINX چیست؟**

ا-**NGINX** یک نرم‌افزار **وب‌سرور (Web Server)** و **Reverse Proxy** بسیار سریع و سبک است. تلفظش معمولاً **اِنجین‌اِکس** است.

کارهای اصلی NGINX شامل این‌هاست:

- نمایش فایل‌های وب مثل HTML، CSS و تصاویر
- دریافت درخواست کاربران و فرستادن آن‌ها به برنامه اصلی
- ا-**Reverse Proxy**
- ا-**Load Balancing** یا تقسیم ترافیک بین چند سرور
- مدیریت HTTPS و SSL
- کش‌کردن محتوا برای افزایش سرعت

مثلاً فرض کن یک برنامه با **Node.js** روی پورت `3000` اجرا شده است. کاربر مستقیماً به Node.js وصل نمی‌شود. درخواست ابتدا به NGINX می‌رسد و NGINX آن را به برنامه
