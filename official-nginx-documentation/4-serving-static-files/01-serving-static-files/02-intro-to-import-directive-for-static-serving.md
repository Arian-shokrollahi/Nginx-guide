# import directive for static serving 

---

#### فایل استاتیک یعنی چی
**فایل استاتیک (Static File)** فایلی است که وب‌سرور آن را همان‌طور که ذخیره شده، به مرورگر ارسال می‌کند؛ بدون اینکه برای هر درخواست، محتوای آن را تولید کند.

مثل فایل‌های **HTML، CSS، JavaScript، عکس و فونت**.

منظور از «استاتیک» این نیست که فایل هیچ‌وقت تغییر نمی‌کند؛ خودت می‌توانی آن را ویرایش کنی. یعنی **محتوای فایل هنگام هر درخواست، به‌صورت پویا در سرور ساخته نمی‌شود.**

مثلاً وقتی مرورگر فایل `style.css` را درخواست می‌کند، Nginx همان فایل ذخیره‌شده را برایش می‌فرستد.


---
#### حالا بریم سراغه دایرکتیو هایه مهم در سرو فایل استاتیک   

|دستور|کاربرد|
|---|---|
|`listen`|تعیین پورت دریافت درخواست|
|`server_name`|تعیین دامنه یا نام سرور|
|`location`|مشخص کردن تنظیمات مربوط به یک مسیر URL|
|`root`|تعیین پوشهٔ اصلی فایل‌ها|
|`index`|تعیین فایل پیش‌فرض برای درخواست پوشه|
|`try_files`|بررسی وجود فایل و تعیین رفتار در صورت نبودن آن|
|`alias`|نگاشت یک مسیر URL به یک پوشهٔ مشخص|
|`include`|وارد کردن تنظیماتی مثل نوع فایل‌ها|
|`expires`|تعیین مدت کش شدن فایل در مرورگر|
|`autoindex`|نمایش فهرست فایل‌های پوشه|
