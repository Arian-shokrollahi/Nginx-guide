این قسمت خیلی مهم است؛ چون اینجا یاد می‌گیریم چطور به Certbot بگوییم اطلاعات محرمانه‌اش را از کجا بخواند.

عبارت موردنظر:

```
--dns-cloudflare-credentials /root/.secret/certbot/cloudflare.ini
```

بیایید آن را به چهار قسمت تقسیم کنیم.

## ۱. بخش اول: `--`

دو خط تیره در ابتدای عبارت نشان می‌دهند که با یک Command-line Option (آرگومان خط فرمان) روبه‌رو هستیم.

در لینوکس و بسیاری از ابزارهای خط فرمان، گزینه‌هایی که با `--` شروع می‌شوند، معمولاً تنظیمات مشخصی را به برنامه منتقل می‌کنند.

## ۲. بخش دوم: `dns-cloudflare`

این قسمت مشخص می‌کند تنظیم موردنظر مربوط به افزونه DNS Cloudflare است.

یعنی به Certbot می‌گوییم تنظیمی که در ادامه می‌آید، مربوط به افزونه Cloudflare است، نه افزونه دیگری مثل Standalone یا Webroot.

## ۳. بخش سوم: `credentials`

این کلمه یعنی اطلاعات احراز هویت.

در واقع به افزونه می‌گوییم قرار است اطلاعات لازم برای احراز هویت نزد Cloudflare را از یک فایل دریافت کند.

این اطلاعات در پروژه ما همان API Token است.

## ۴. بخش چهارم: مسیر فایل

```
/root/.secret/certbot/cloudflare.ini
```

این قسمت مسیر دقیق فایل Credentials را مشخص می‌کند.

|بخش مسیر|معنی|
|---|---|
|`/`|ریشه فایل‌سیستم Linux|
|`root`|پوشه خانگی کاربر Root|
|`.secret`|پوشه مخفی اطلاعات محرمانه|
|`certbot`|پوشه مخصوص Certbot|
|`cloudflare.ini`|فایل تنظیمات حاوی API Token|
