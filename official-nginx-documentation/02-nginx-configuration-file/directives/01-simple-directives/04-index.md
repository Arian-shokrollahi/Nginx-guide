# index 

---
## 1. مقدمه و تعریف Directive `index` در Nginx

دایرکتیو `index` در Nginx مشخص می‌کند که وقتی کاربر یک دایرکتوری از وب‌سایت را درخواست می‌کند، چه فایل‌هایی به‌ترتیب به‌عنوان فایل پیش‌فرض (Default Index File) بررسی شوند.

برای مثال، وقتی کاربر آدرس اصلی سایت مثل `http://example.com/` را باز می‌کند، Nginx باید بداند کدام فایل را به او نمایش دهد. اینجاست که از دایرکتیو `index` استفاده می‌کنیم.

---

## 2. دایرکتیو `index کجا استفاده می‌شود؟

از این دایرکتیو معمولاً در بخش `server` یا `location` در کانفیگ Nginx استفاده می‌شود.

- تعیین صفحه اصلی سایت: مشخص می‌کند هنگام باز شدن آدرس اصلی سایت، کدام فایل به‌عنوان صفحه پیش‌فرض انتخاب شود.
    
- تعیین صفحه پیش‌فرض دایرکتوری‌ها: مثلاً وقتی کاربر وارد `/blog/` می‌شود، Nginx فایل شاخص داخل دایرکتوری `blog` را بررسی می‌کند.
    
- تعیین اولویت فایل‌ها: اگر چند نام فایل تعریف کنیم، Nginx آن‌ها را به‌ترتیب بررسی می‌کند؛ اگر فایل اول پیدا نشود، سراغ فایل بعدی می‌رود.
    

---

## 3. مثال عملی

فرض کن کانفیگ Nginx به این صورت باشد:

```
server {
    listen 80;
    server_name example.com;

    root /var/www/html;
    index index.html index.htm;
}
```

و ساختار فایل‌های سایت این باشد:

```
/var/www/html/
├── index.htm
└── about.html
```

حالا اگر کاربر آدرس زیر را باز کند:

```
http://example.com/
```

Nginx این مراحل را طی می‌کند:

1. ابتدا فایل `index.html` را بررسی می‌کند.
    
2. چون این فایل وجود ندارد، سراغ `index.htm` می‌رود.
    
3. چون `index.htm` وجود دارد، محتوای آن به کاربر ارائه می‌شود.
    

اما اگر هر دو فایل `index.html` و `index.htm` وجود داشته باشند، در شرایط عادی `index.html` انتخاب می‌شود، چون در فهرست `index` اول آمده است.

نکته مهم: دایرکتیو `index` فایل‌ها را به‌ترتیب اجرا نمی‌کند؛ فقط مشخص می‌کند کدام فایل به‌عنوان صفحه پیش‌فرض انتخاب شود.

---

## 4-پس وظیفه ی دایرکتیو index چیست؟

وظیفه اصلی دایرکتیو `index` در Nginx، تعیین فایل پیش‌فرض دایرکتوری و اولویت‌بندی فایل‌هایی است که باید به‌ترتیب بررسی شوند.

مثلاً:

```
index index.html index.htm default.html;
```

یعنی:

- اولویت اول: `index.html`
    
- اولویت دوم: `index.htm`
    
- اولویت سوم: `default.html`
    

اگر فایل اول پیدا نشه، Nginx سراغ فایل بعدی می‌ره؛ اگر فایل اول موجود باشه، همون رو انتخاب می‌کنه.

پس یادت باشه: اولویت‌بندی، بخشی از وظیفه `index` است؛ هدف اصلی آن تعیین فایل شاخص (Index File) برای دایرکتوری‌هاست.
