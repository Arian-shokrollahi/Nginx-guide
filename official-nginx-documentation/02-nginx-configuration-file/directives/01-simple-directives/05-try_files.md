# try_files
---
## ۱-اول دایرکتیو try_files ؟

دایرکتیو `try_files` در Nginx بررسی می‌کنه که آیا فایل یا دایرکتوری موردنظر وجود داره یا نه.

--- 

## ۲- تعریف سادش چیه و ساختارش به چه صورته

تعریف ساده:

ا-`try_files` به Nginx می‌گه:

«اول این مسیر رو بررسی کن؛ اگر وجود نداشت، مسیر بعدی رو امتحان کن. اگر هیچ‌کدوم پیدا نشدن، برو سراغ آخرین گزینه.»

ساختار کلی:

```
try_files file1 file2 ... fallback;
```

مثال:

```
location / {
    try_files $uri $uri/ =404;
}
```

یعنی:

1. اول بررسی کن آیا فایلی مطابق درخواست کاربر وجود داره؟
    
2. اگر نبود، بررسی کن آیا دایرکتوری مطابق درخواست وجود داره؟
    
3. اگر هیچ‌کدوم نبود، خطای `404 Not Found` برگردون.
---

## ۳- uri$ و /uri$ یعنی چی با مثال 

فرض کن این ساختار رو داری:

```
/var/www/html/
├── index.html
├── about.html
├── style.css
└── images/
    └── logo.png
```

و تنظیمات Nginx به این شکل هست:

```
server {
    listen 80;
    server_name localhost;

    root /var/www/html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

حالا فرض کن کاربر این آدرس رو درخواست می‌کنه:

```
http://localhost/about.html
```

ا-Nginx مقدار `$uri` رو برابر `/about.html` در نظر می‌گیره و فایل زیر رو بررسی می‌کنه:

```
/var/www/html/about.html
```

چون فایل وجود داره، همون رو ارائه می‌ده.

---
### ۴- فرقه بین  uri$  و /uri$

در `try_files`، عبارت `$uri` وجود فایل و عبارت `$uri/` وجود دایرکتوری را بررسی می‌کند.

|عبارت|کاربرد|مثال|
|---|---|---|
|`$uri`|بررسی وجود فایل|`/var/www/html/about.html`|
|`$uri/`|بررسی وجود دایرکتوری|`/var/www/html/images/`|

نکته: `$uri/` متغیر مستقلی نیست؛ همان `$uri` با یک `/` در انتهاست.
