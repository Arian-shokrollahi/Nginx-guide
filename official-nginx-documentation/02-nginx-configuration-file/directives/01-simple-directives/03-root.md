# root
---
## ۱-دایرکتیو root چیست؟
دستور **root** در Nginx مشخص می‌کند **فایل‌های سایت در کدام پوشهٔ سرور قرار دارند**؛ مثلاً فایل‌های HTML، CSS و عکس‌ها.


یا بهتر 


ا-**`root` یک Simple Directive است** و می‌تواند داخل بلاک‌های `http`، `server` و `location` نوشته شود. برای تعیین پوشهٔ اصلی یک سایت، معمولاً آن را داخل `server` می‌نویسیم.


---
## ۲-دایرکتیو root   چه کمکی به ما میکند 

**«دستور `root` مسیر پایهٔ فایل‌های سایت را مشخص می‌کند و به Nginx می‌گوید برای پیدا کردن فایل‌های درخواستی، از کدام پوشه استفاده کند.»**

```
root /var/www/site;
```

مثلاً درخواست `/images/logo.png` به این مسیر نگاشت می‌شود:

```
/var/www/site/images/logo.png
```

---
## ۳-وقتی کاربر این آدرس را درخواست کند:

```
http://example.com/style.css
```

Nginx مسیر درخواست را به مقدار `root` اضافه می‌کند و دنبال این فایل می‌گردد:

```
/var/www/example/style.css
```

مثال‌های بیشتر:

|مسیر درخواست کاربر|مسیر فایل روی سرور|
|---|---|
|`/index.html`|`/var/www/example/index.html`|
|`/images/logo.png`|`/var/www/example/images/logo.png`|
|`/css/style.css`|`/var/www/example/css/style.css`|

---
