#  ترتیب یادگیری دایرکتیو هایه بلاکی
---
برای مسیری که شروع کردی، **از `http` شروع کن، بعد `server` و سپس `location`**؛ این سه تا پایهٔ تنظیم سایت در nginx هستند.

|ترتیب|بلوک|چه چیزی یاد بگیری؟|
|---|---|---|
|۱|`http`|محیط تنظیمات وب؛ تنظیمات مشترک سایت‌ها اینجا قرار می‌گیرند|
|۲|`server`|تعریف هر سایت؛ نقش `listen` و `server_name`|
|۳|`location`|انتخاب تنظیمات بر اساس مسیر درخواست؛ همراه با `root` و `alias`|
|۴|`events`|مدیریت اتصال‌ها؛ همراه با `worker_connections`|
|۵|`upstream`|تعریف سرورهای مقصد؛ برای یادگیری پروکسی و تقسیم درخواست‌ها|
|۶|`map`|تعیین مقدار متغیر بر اساس مقدار دیگری|

**فعلاً روی سه تای اول تمرکز کن** و این ساختار را خوب بفهم:

```
http {
    server {
        listen 8080;
        server_name localhost;

        location /images/ {
            root /var/www;
        }
    }
}
```

در مثال عکست، باید بتوانی توضیح بدهی **درخواست به کدام `server` می‌رسد، کدام `location` انتخاب می‌شود و مسیر فایل چگونه ساخته می‌شود**.

بعد سراغ `events` و `upstream` برو. بلوک‌های `types`، `geo`، `limit_except` و `if` را هنگام نیاز یاد بگیر؛ `stream` و `mail` هم برای کاربردهای جداگانه‌اند.
