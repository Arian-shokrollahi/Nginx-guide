## مقدمه ای بر فایل کانفیگ etc/nginx.conf/
---
### 1-فایل کانفیگ چیست؟
فایل **`nginx.conf`**، فایل اصلی تنظیمات Nginx است.
-  که بسته ب مدل نصبتون میتونه در مسیر هایه مختلف باشد
---
## 2-حالا بریم درمورد ساختار nginx صحبت کنیم:

این بخش دربارهٔ **ساختار فایل تنظیمات Nginx** صحبت می‌کنه.

ا-Nginx از **ماژول‌ها (Modules)** تشکیل شده؛ هر ماژول بخشی از قابلیت‌های برنامه رو فراهم می‌کنه. این ماژول‌ها با **دستورهای تنظیماتی (Directives)** داخل فایل تنظیمات کنترل می‌شن.

- `دستورهای تنظیماتی دو نوع دارن:`

**۱. دستور ساده — <mark> Simple directive</mark>

از **نام دستور و پارامترها** تشکیل می‌شه که با فاصله از هم جدا می‌شن و در پایان **`;`** قرار می‌گیره.

```
pid /var/run/nginx.pid;
```

در این مثال:

- نام دستور: `pid`
- پارامتر: `/var/run/nginx.pid`
- پایان دستور: `;`

**۲. دستور بلوکی — <mark>  Block directive
</mark>
مثل دستور ساده، نام و پارامتر داره، اما به‌جای پایان با `;`، مجموعه‌ای از دستورهای بیشتر رو داخل **`{ }`** قرار می‌ده.

```
events {
    worker_connections 1024;
}
```

اینجا دستور **`events` بلوکی** است و دستور **`worker_connections` ساده** است.

---

## 3-کانتکست (Context) یعنی چی؟

اگر یک دستور بلوکی اجازه بده دستورهای دیگه داخل آکولادهاش قرار بگیرن، به اون **کانتکست** می‌گن. کانتکست مشخص می‌کنه دستورهای داخلش در چه محدوده‌ای کاربرد دارن.

مثال‌های متن: **`events`، `http`، `server` و `location`**.

```
http {
    server {
        listen 80;

        location / {
            root /var/www/html;
        }
    }
}
```

در این مثال، کانتکست **`server` داخل `http`** و کانتکست **`location` داخل `server`** قرار گرفته؛ دستورهای **`listen` و `root`** هم ساده هستن.

**برای یادداشتت:** دستور ساده با **`;`** تمام می‌شه؛ دستور بلوکی از **`{ }`** استفاده می‌کنه؛ بلوکی که دستورهای دیگه رو داخل خودش می‌پذیره، **کانتکست** نام داره.
