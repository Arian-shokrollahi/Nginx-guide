# مسیر فایل پیکربندی درون nginx
---
مسیر رایج فایل اصلی پیکربندی Nginx در لینوکس اینه:

```
/etc/nginx/nginx.conf
```
- معمولا درون این مسیره 
بسته به روش نصب، ممکنه اینجا هم باشه:

```
/usr/local/nginx/conf/nginx.conf
/usr/local/etc/nginx/nginx.conf
```

**برای پیدا کردن مسیر پیش‌فرض در نصب خودت** این دستور رو بزن:

```
nginx -V 2>&1 | grep -o -- '--conf-path=[^ ]*'
```

اگر Nginx با گزینهٔ **`-c`** اجرا شده باشه، از فایل تنظیمات مشخص‌شده با اون گزینه استفاده می‌کنه، نه لزوماً مسیر پیش‌فرض.
