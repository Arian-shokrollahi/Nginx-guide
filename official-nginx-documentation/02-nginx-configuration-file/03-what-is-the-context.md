# context
---
## ۱-کانتکست (context) چیه؟
**کانتکست (Context) یعنی محدوده‌ای در فایل تنظیمات Nginx که دستورهای تنظیماتی داخلش قرار می‌گیرن.** این محدوده مشخص می‌کنه هر دستور کجا کاربرد داره و روی چه بخشی اثر می‌ذاره.

---
## ۲-ما چند نوع کانتکست (context) داریم؟
| کانتکست                  | کاربرد                                          | محل قرارگیری          |
| ------------------------ | ----------------------------------------------- | --------------------- |
| اصلی **`main` (global)** | تنظیمات کلی مثل `pid` و `worker_processes`      | بیرون از تمام بلوک‌ها |
| رویدادها **`events`**    | تنظیمات اتصال‌ها، مثل `worker_connections`      | داخل `main`           |
| وب **`http`**            | تنظیمات کلی سرویس HTTP                          | داخل `main`           |
| سرور **`server`**        | تنظیمات یک سایت یا سرور مجازی                   | داخل `http`           |
| مسیر **`location`**      | نحوهٔ رسیدگی به مسیرهای درخواست، مثل `/images/` | داخل `server`         |

---
## ۳- یه مثال و جدولی درمورد توضیح کاربرد هر کانتکس

مثلاً:

```
events {
    worker_connections 1024;
}
```

اینجا **`events` یک کانتکست** است و دستور `worker_connections` داخل اون قرار گرفته.

- توضیح درمورد توضیح هر ۵ کانتکست

|کانتکست|کاربرد|
|---|---|
|اصلی **`main` یا global**|تنظیمات کلی Nginx، مثل تعداد Workerها و مسیر فایل PID|
|رویدادها **`events`**|تنظیمات مدیریت اتصال‌ها|
|وب **`http`**|تنظیمات کلی HTTP|
|سرور **`server`**|تنظیمات یک سایت یا سرور مجازی|
|مسیر **`location`**|تنظیمات مربوط به یک مسیر درخواست، مثل `/images/`|

**کانتکست‌ها می‌تونن داخل هم قرار بگیرن:** برای نمونه، `server` داخل `http` و `location` داخل `server` قرار می‌گیره.

**دو نکتهٔ مهم:**

- کانتکست اصلی **آکولاد جداگانه نداره**؛ دستورهای بیرون از بلوک‌ها در کانتکست `main` هستن.
- تعداد کل <mark>کانتکست‌ها فقط پنج تا نیست</mark>؛ موارد دیگری مثل **`stream` و `mail`** هم وجود دارن. هر دستور هم فقط در کانتکست‌های مجاز خودش قابل استفاده است.
