# بریم درون پارت سوم خرید دامنه تا گرفتن گواهی رو یک بار مراحلش رو مرور کنیم 

---


## مرحله ۱: انتخاب و خرید دامنه از NIC.ir

1. وارد سایت [NIC.ir](https://www.nic.ir/?utm_source=chatgpt.com) می‌شویم.

2. اگر حساب کاربری نداریم ثبت‌نام می‌کنیم.

3. دامنه موردنظرمان را انتخاب و آزادبودن آن را بررسی می‌کنیم.

4. برای احراز هویت، در صورت نیاز وارد سامانه هُدا (هویت دیجیتال ایرانیان) می‌شویم.

5. احراز هویت را انجام می‌دهیم.

6. دامنه را ثبت و هزینه آن را پرداخت می‌کنیم.

7. منتظر تأیید و فعال‌شدن دامنه می‌مانیم.

---
## مرحله ۲: انتخاب DNS Provider

1. وارد سایت [Cloudflare](https://www.cloudflare.com/?utm_source=chatgpt.com) می‌شویم.
    
2. حساب کاربری ایجاد می‌کنیم.
    
3. دامنه خریداری‌شده را به Cloudflare اضافه می‌کنیم.
    
4. پلن موردنظر (برای پروژه ما Free) را انتخاب می‌کنیم.
    
5. ا-Cloudflare دو Nameserver اختصاصی به ما می‌دهد.
    

مثلاً برای دامنه ما:

```
aron.ns.cloudflare.com
garrett.ns.cloudflare.com
```

---
## مرحله ۳: تنظیم Nameserver در NIC

1. وارد پنل NIC می‌شویم.
    
2. به تنظیمات دامنه و بخش DNS یا کارگزارهای دامنه می‌رویم.
    
3. دو Nameserver دریافتی از Cloudflare را وارد می‌کنیم.
    
4. چون Nameserverها متعلق به یک شرکت خارجی هستند، فیلد IP را خالی می‌گذاریم.
    
5. تغییرات را ذخیره می‌کنیم.

---
## مرحله ۴: DNS Delegation

در این مرحله NIC باید اطلاعات واگذاری دامنه را در Zone والد `.ir` منتشر کند.

به این فرایند Delegation می‌گوییم.

یعنی به NIC می‌گوییم:

«مدیریت DNS دامنه من را به Nameserverهای Cloudflare واگذار کن.»

منتظر انتشار و قابل مشاهده‌شدن این تغییرات می‌مانیم.

---
## مرحله ۵: تست Delegation با dig

تست مستقیم از NIC:

```
dig @a.nic.ir shokbil.ir NS +norecurse
```

تست از DNS عمومی Cloudflare:

```
dig @1.1.1.1 NS shokbil.ir +short
```

تست مستقیم Nameserver اول:

```
dig @aron.ns.cloudflare.com shokbil.ir SOA +norecurse
```

تست مستقیم Nameserver دوم:

```
dig @garrett.ns.cloudflare.com shokbil.ir SOA +norecurse
```

اگر پاسخ‌ها صحیح باشند، می‌توانیم از عملکرد Delegation و Nameserverها مطمئن شویم.

---

## مرحله ۶: ساخت DNS Record در Cloudflare

حالا که Cloudflare مدیریت DNS را بر عهده گرفته، می‌توانیم وارد بخش DNS Records شویم.

انواع رکوردهای مهم:

|Record|کاربرد|
|---|---|
|A|اتصال دامنه به IPv4|
|AAAA|اتصال دامنه به IPv6|
|CNAME|معرفی نام مستعار برای یک دامنه|
|MX|مشخص‌کردن سرور ایمیل|
|TXT|ذخیره اطلاعات متنی و اعتبارسنجی|

مثلاً برای اتصال دامنه به وب‌سرور:

```
Type: A
Name: @
Content: SERVER_PUBLIC_IP
```

نکته: این IP مربوط به وب‌سرور است، نه Nameserver.

# ۱. اصطلاحات مربوط به خرید دامنه (Domain Registration)

|اصطلاح|معنی فارسی|توضیح|
|---|---|---|
|Domain|دامنه|نام وب‌سایت؛ مثل `shokbil.ir`|
|Domain Name|نام دامنه|نامی که کاربران برای دسترسی به سایت وارد می‌کنند.|
|TLD|دامنه سطح بالا|پسوند دامنه مثل `.com` و `.ir`|
|Suffix|پسوند|قسمت انتهایی نام دامنه|
|Registrar|ثبت‌کننده دامنه|شرکتی که از طریق آن دامنه را ثبت و خریداری می‌کنیم.|
|Registry|مرجع ثبت دامنه|سازمانی که اطلاعات دامنه‌های یک پسوند را مدیریت می‌کند.|
|Registrant|مالک دامنه|شخص یا سازمانی که دامنه به نام او ثبت شده است.|
|Registration|ثبت دامنه|فرایند ثبت مالکیت دامنه|
|Authentication|احراز هویت|تأیید هویت شخص ثبت‌کننده دامنه|
|HODA|هویت دیجیتال ایرانیان|سامانه احراز هویت دیجیتال در ایران|

مثال پروژه ما:

- Domain: `shokbil.ir`
    
- TLD: `.ir`
    
- Registrar / Registry: NIC.ir در نقش ثبت و مدیریت دامنه‌های `.ir`
    

نکته: Registrar و Registry دو نقش متفاوت هستند؛ Registrar واسطه ثبت دامنه است، اما Registry پایگاه اصلی اطلاعات دامنه‌های یک پسوند را مدیریت می‌کند.

# ۲. اصطلاحات مربوط به DNS

|اصطلاح|معنی فارسی|توضیح|
|---|---|---|
|DNS|سیستم نام دامنه|نام دامنه را به اطلاعاتی مثل IP تبدیل یا مرتبط می‌کند.|
|DNS Provider|ارائه‌دهنده DNS|سرویسی که مدیریت DNS دامنه را بر عهده می‌گیرد؛ مثل Cloudflare|
|DNS Server|سرور DNS|سروری که درخواست‌های DNS را دریافت و پاسخ می‌دهد.|
|Nameserver (NS)|سرور نام|سروری که اطلاعات DNS یک دامنه را به‌صورت معتبر ارائه می‌کند.|
|DNS Resolver|حل‌کننده DNS|سرویسی که درخواست DNS کاربر را دنبال می‌کند تا پاسخ را پیدا کند.|
|Recursive Resolver|حل‌کننده بازگشتی|برای پیدا کردن پاسخ، در صورت نیاز از سرورهای DNS دیگر سؤال می‌کند.|
|Authoritative DNS|DNS مرجع|سروری که پاسخ معتبر مربوط به Zone دامنه را ارائه می‌دهد.|
|DNS Record|رکورد DNS|اطلاعات ذخیره‌شده درباره دامنه|
|DNS Zone|ناحیه DNS|محدوده‌ای از فضای نام DNS که رکوردهای آن مدیریت می‌شوند.|
|Zone File|فایل Zone|فایلی که اطلاعات رکوردهای DNS را نگهداری می‌کند.|

### انواع مهم DNS Record

|نوع رکورد|کاربرد|
|---|---|
|A|اتصال نام دامنه به IPv4|
|AAAA|اتصال نام دامنه به IPv6|
|CNAME|ایجاد نام مستعار برای یک نام دامنه دیگر|
|MX|مشخص‌کردن سرور دریافت ایمیل|
|TXT|ذخیره اطلاعات متنی و اعتبارسنجی|
|NS|معرفی Nameserverهای دامنه|
|SOA|اطلاعات اصلی و مدیریتی Zone|
|PTR|تبدیل IP به نام دامنه (Reverse DNS)|
|DS|نگهداری اطلاعات کلید DNSSEC در Zone والد|

مثلاً:

```
shokbil.ir  →  192.0.2.10
```

در این مثال یک رکورد A داریم.

# ۳. اصطلاحات مربوط به اتصال NIC به Cloudflare

این قسمت از مهم‌ترین بخش‌های پروژه ماست.

|اصطلاح|معنی فارسی|توضیح|
|---|---|---|
|Delegation|واگذاری|واگذاری مدیریت DNS دامنه به Nameserverهای دیگر|
|Parent Zone|ناحیه والد|ناحیه بالادستی دامنه؛ مثلاً `.ir`|
|Child Zone|ناحیه فرزند|ناحیه دامنه‌ای که مدیریت آن واگذار می‌شود؛ مثل `shokbil.ir`|
|Glue Record|رکورد چسبنده|اطلاعات IP کمکی برای حل وابستگی دوری Nameserver|
|Propagation|انتشار تغییرات|قابل مشاهده‌شدن تغییرات DNS در Resolverهای مختلف|
|TTL|زمان ماندگاری|مدت زمانی که پاسخ DNS می‌تواند در Cache نگهداری شود.|
|DNSSEC|امنیت DNS|مکانیزمی برای اعتبارسنجی اصالت پاسخ‌های DNS|
|DS Record|رکورد امضای دیجیتال|اطلاعات مربوط به کلید DNSSEC در Zone والد|

### Delegation دقیقاً چه بود؟

ما در NIC این دو Nameserver را ثبت کردیم:

```
aron.ns.cloudflare.com
garrett.ns.cloudflare.com
```

یعنی به Zone والد `.ir` اعلام کردیم که مسئول پاسخ‌گویی معتبر DNS دامنه `shokbil.ir` این دو Nameserver هستند.

این فرایند را Delegation می‌نامیم.

### Glue Record چیست؟

فرض کن Nameserver ما این باشد:

```
ns1.company.com
```

اگر بخواهیم دامنه `company.com` را به همین Nameserver واگذار کنیم، برای پیدا کردن IP سرور ممکن است با وابستگی دوری مواجه شویم.

برای حل این مشکل از Glue Record استفاده می‌کنیم.

## ۹. ده اصطلاحی که باید حتماً حفظ باشی

اگر بخواهم از تمام این مطالب ده اصطلاح کلیدی انتخاب کنم، این‌ها هستند:

1.ا- Registrar: ثبت‌کننده دامنه.
    
2. ا-DNS Provider: ارائه‌دهنده خدمات مدیریت DNS.
    
3. ا-Nameserver: سرور معتبر ارائه‌دهنده اطلاعات DNS دامنه.
    
4.ا- DNS Resolver: سرویسی که پاسخ DNS را برای درخواست‌کننده پیدا می‌کند.
    
5.ا- Delegation: واگذاری مدیریت DNS دامنه.
    
2. ا-DNS Record: اطلاعات ذخیره‌شده در DNS.
    
3.ا- API Token: اعتبارنامه دسترسی نرم‌افزار به API.
    
2.ا- Certbot: نرم‌افزار دریافت و مدیریت Certificate.
    
2. ا-Certificate: گواهی دیجیتال هویت سرور.
    
3. ا-Private Key: کلید خصوصی و محرمانه سرور.
