# listen directive for HTTPS
---
# 1-برایه اینکه بخواهیم از HTTPS استفاده کنیم  باید چیکار کنیم:

برای اینکه بخواهیم از HTTPS استفاده کنیم، اولین Directive که باید به آن توجه کنیم `listen` است. این Directive باید روی پورت `443` همراه با پارامتر `ssl` تنظیم شود:

```
listen 443 ssl;
```

پورت 443 پورت استاندارد HTTPS است و پارامتر `ssl` مشخص می‌کند که ارتباط ورودی روی این پورت از طریق TLS برقرار شود.

---
# 2-**حالت‌های مختلف listen**

**حالت اول: HTTPS استاندارد**

```
listen 443 ssl;
```

**حالت دوم: گوش دادن روی تمام IPv4ها**

```
listen 0.0.0.0:443 ssl;
```

**حالت سوم: گوش دادن روی IPv6**

```
listen [::]:443 ssl;
```

**حالت چهارم: گوش دادن روی IPv4 و IPv6**

```
listen 443 ssl;
listen [::]:443 ssl;
```

### . نکته مهم Production**

این دو دستور را با هم مقایسه کن:

```
listen 80;
listen 443 ssl;
```

- پورت 80 برای HTTP است.
    
- پورت 443 برای HTTPS است.

---
# 3-نکات پایانی مهم

1. اگر سرور IPv4 و IPv6 را پشتیبانی می‌کند، باید Listener مربوط به IPv6 را هم در نظر بگیری.
    
2. پورت 443 باید در Firewall و Security Group باز باشد.
    
3. باید Certificate و Private Key معتبر معرفی شده باشند.
    
4. نباید برای یک آدرس و پورت، تنظیمات متناقض یا تکراری تعریف کنی.
    

**نتیجه:** برای راه‌اندازی HTTPS در Nginx، همین `listen 443 ssl;` نقطه شروع استاندارد است و نیازی به پارامتر اضافی خاصی برای فعال‌سازی HTTPS نداری.
